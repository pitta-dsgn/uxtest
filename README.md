# Апрель: прототип оформления заказа

Статический прототип для UX-тестирования: корзина → выбор аптеки → оформление → завершение.

## Запуск

Опубликованный прототип: https://pitta-dsgn.github.io/uxtest/

GitHub Pages публикует корень ветки `main`. Сборка не нужна: `index.html`, `styles.css`, `app.js` и папка `images/`.

## Сценарий

- В корзине три товара, клубные цены применены. Названия показываются полностью.
- У аптеки на ул. Солнцедарской, 2Д синусэфрин доступен под заказ. В 8 из 28 аптек один или два товара под заказ, в одной аптеке один товар недоступен.
- Нажатие на статус раскрывает товары прямо в списке. Нажатие на адрес или метку открывает выбранную аптеку; продолжить оформление можно только с Солнцедарской.
- Точка пользователя задана на Кирова, 25 (44.5583876, 38.0793139). Расстояния вычисляются по прямой формулой гаверсинуса, список сортируется от ближайшей аптеки. Источник координат: https://www.openstreetmap.org/way/105878326
- Кластеры привязаны к реальной аптеке внутри группы, а не к средним координатам: это исключает положение маркера посреди бухты.
- Работают поиск произвольного адреса, избранное, карта OSM, кластеризация меток, три положения панели и прокрутка зажатой левой кнопкой мыши.
- Доступны три способа оформления, состояния оплаты, промокод APRIL200, ошибка промокода, удаление с возвратом в течение трёх секунд, завершение и отмена заказа.
- Тестовые данные сохраняются в sessionStorage текущей вкладки. Персональные данные и реальные заказы никуда не отправляются.

## Ресурсы

Все изображения и SVG подключены относительными путями из `images/`. В HTML/JS нет встроенных base64-картинок или временных ссылок Figma.

Изображения парацетамола и синусэфрина восстановлены вместо пустых экспортов; добавлены отсутствовавшие терафлю, Energy Sol и Флюфайт. Остальные загруженные ресурсы сохранены.

## Проверка

```sh
node --check app.js
node test-scenario.cjs
```

Проверки покрывают основную и альтернативные ветки оформления, поиск, промокод, возврат удалённого товара, избранное, раскрытие наличия, ограничение выбора аптеки, карту и жесты мышью. Для реальных тайлов и шрифта требуется интернет.
